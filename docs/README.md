# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
# About
Geometric Lib is a small Python library with area and perimeter formulas for basic figures.

## Contents
- `circle.py` - area and perimeter of a circle
- `square.py` - area and perimeter of a square
